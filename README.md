# 坦途·抽奖大转盘

一个无需安装依赖的单页抽奖应用。名单和抽奖参数保存在同一个 JSON 文件中，由使用者手动导入。

## 快速开始

1. 双击打开 index.html。
2. 首次打开时点击转盘下方“请先导入配置”，选择项目中的 lottery.json；导入后可用右上角“导入配置”重新导入。
3. 导入后即可抽奖。无需启动 HTTP 服务，也不需要 BAT 文件。

页面不内置人员名单或默认抽奖配置；每次重新打开页面后都需要手动导入配置。
页面同一时刻只显示一个导入入口：未导入时使用转盘按钮，导入后使用右上角按钮。

## GitHub Pages

项目发布到 GitHub Pages 后，可通过 <https://douersepper.github.io/tantu_lottery/> 在线打开。向 `main` 分支推送 `index.html` 或部署工作流后，会自动更新网页。

在线页面仍需手动导入 JSON 配置。仓库和网页是公开的；为保护名单中的实际姓名，`lottery.json` 保留在本机，不提交到仓库，Pages 部署也只发布 `index.html`。使用在线页面时，在文件选择器中选择你本机保存的配置文件。

## 配置文件

名单和抽奖参数使用一个 JSON 文件，结构如下：

    {
      "version": 1,
      "people": [
        { "id": "1", "name": "示例姓名" },
        { "id": "2", "name": "另一位示例人员" }
      ],
      "spin": {
        "minimumSpinDurationSeconds": 10,
        "maximumSpinDurationSeconds": 16,
        "removeWinnerAfterDraw": true
      }
    }

| 字段 | 说明 |
| --- | --- |
| people | 参与名单数组。每人必须有唯一、非空的 id 和非空的 name。 |
| minimumSpinDurationSeconds | 本次转动时长的下限，范围为 3–60 秒。 |
| maximumSpinDurationSeconds | 本次转动时长的上限；需大于或等于下限，且不超过 60 秒。应用会在区间内随机选择时长。 |
| removeWinnerAfterDraw | 布尔值。为 true 时，中奖者不再参加本轮后续抽奖；为 false 时仍可再次中奖。 |

本机的 lottery.json 是可直接导入的当前配置。修改人员或参数时，编辑该文件后重新导入即可；此文件不会随公开网页或仓库发布。

## 抽奖操作

- 鼠标快速点击抽奖按钮即可抽奖；按住按钮并松开也会开始转动。
- 页面焦点不在输入框或其他控件时，按住空格蓄力、松开开始转动。空格不会滚动页面；在姓名输入框里仍可正常输入空格。
- 蓄力最长 2 秒，最多增加 8 圈；每次抽奖至少转 4 圈。快速点击也能完成抽奖，不设最低蓄力门槛。
- 转动时长按配置随机选择，转盘会逐渐减速，右侧指针所指人员为中奖者。
- 中奖者揭晓前会留出约 1 秒辨认时间；庆祝彩带为 60 个，单片动画约 4 秒。中奖记录只保存在当前页面会话中，本轮显示全部记录；刷新或重新导入后会清空。
- 中奖揭晓页打开时，按空格可关闭并继续；焦点位于“关闭并继续”按钮时，按空格也会触发按钮。
- “重置本轮”会清空本轮中奖记录并恢复可抽人员，不会删除名单。
- 左上角图标可展开或收起“抽奖设置”，设置卡片默认收起。

名单可在页面中添加或删除；这些编辑只影响当前页面，不会写回 JSON，也不会保存到浏览器。重新导入配置时始终以所选 JSON 中的名单为准；刷新页面后再次导入，也会恢复配置文件里的原始名单。

## 项目文件

- index.html：页面、样式和抽奖逻辑，均以内联 CSS/JavaScript 实现。
- lottery.json：当前名单和抽奖参数。
- README.md：使用与配置说明。
- AGENTS.md：本项目后续代码修改的约定。

项目没有构建步骤、包管理器或第三方运行时依赖。

## 页面布局

页面左右边距随屏幕宽度平滑变化，窄屏保持 20px、1920px 宽约 100px；桌面转盘与侧栏约为 1.414:1，卡片间距 20px，窄屏切换为单栏。圆心文字和中奖展示会随窄屏或矮窗口适当缩小。人员名单完整展开，不在名单卡片内单独滚动。桌面中奖记录按条目自然增高，超出转盘卡片底部后才在记录列表内滚动；窄屏随页面自然展开。

字体按平台回退：Windows 优先使用 Microsoft YaHei UI；macOS 使用 `system-ui`，英文匹配系统 SF 字体，中文回退到 PingFang SC。Canvas 转盘文字也使用同一字体栈。
